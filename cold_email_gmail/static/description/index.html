Cold Email (Gmail API)

Schedule one-off emails and send them through the Gmail REST API, with no SMTP and no passwords.

11 USD

Connect with Google OAuth 2.0

One mailbox per user. Every Gmail operation is an HTTPS call to gmail.googleapis.com. No ir.mail_server, mail.mail or fetchmail.

Compose and schedule

Write From, To, Subject and an HTML body, then pick when it goes out. Use tags and saved templates, and type / to insert the recipient's name or company.

Safe automatic sending

A cron sends everything that is due, respecting each mailbox's daily limit, pacing and sending window.

Bounce detection

Bounced messages are detected and marked, so your list stays clean.

Chatter and follow-ups

Discuss, log notes and schedule follow-up activities on each email.
